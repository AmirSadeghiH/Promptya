{% comment %} Verified-creator badge — the single source of truth for this mark. It used to be a bare "✔" text glyph in every template, which rendered at a different weight, baseline and size on each platform's emoji font. This is a drawn badge instead: a solid accent disc with a knocked-out check, so it stays identical across platforms, themes and RTL. Param: label — optional accessible label. Omit it where an adjacent heading already names the creator (then the badge is decorative and aria-hidden). Sizing comes from the .verified class; it inherits `currentColor` so it picks up the accent in every context it appears in. {% endcomment %}
